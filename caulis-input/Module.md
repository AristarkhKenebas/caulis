# Module caulis-input

The plain types of input that everything handling input shares: [dev.caulis.core.input.InputSettings]
and its enums, gestures, scrolling, the tablet value types. Nothing here talks to clients
(the seat and the keymap are in `caulis-core`). `caulis-core` brings it.

# Package dev.caulis.core.input

Plain input types; the rest of this package is in `caulis-core`.
