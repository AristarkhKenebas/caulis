# Module caulis-lua

`config.lua`: a compositor's configuration in Lua (LuaJ, Lua 5.2 on the JVM). A compositor
with this module on its class path reads `config.lua` from its folder by itself. See the
guide, step 26.

# Package dev.caulis.lua

[dev.caulis.lua.LuaConfig]: what `config.lua` can say (the `caulis` table).
