# Module caulis-protocol

The Wayland protocol, implemented from scratch: the wire format, the server side
([dev.caulis.protocol.Display], clients, objects) and a client side. Classes for each
protocol are generated from its XML description.

# Package dev.caulis.protocol

Sockets, clients, objects ([dev.caulis.protocol.Resource]) and messages.

# Package dev.caulis.protocol.client

The client side, used to run as a window inside another compositor.
