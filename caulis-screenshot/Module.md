# Module caulis-screenshot

Screenshots inside a Caulis compositor: the screen frozen at once, a toolbar to choose an
area, a window or a monitor (with or without the pointer, at once or after a few seconds),
saved as PNG and put on the clipboard. Optional: `screenshots()` in a configuration binds
Print, Shift+Print and Alt+Print; with this module on the class path, text configurations
have the `screenshot` action. See the guide, step 19.
