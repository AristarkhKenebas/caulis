# Module caulis-log

The log of Caulis: levels 0 (nearly silent) to 3 (everything, step by step), for everything
or for single areas (`wayland`, `focus`, `render`, ...). See [dev.caulis.log.Log].

# Package dev.caulis.log

[dev.caulis.log.Log] (the settings) and [dev.caulis.log.Logger] (one area's log).
