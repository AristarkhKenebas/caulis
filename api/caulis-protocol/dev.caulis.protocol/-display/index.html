Display

class Display(val loop: EventLoop) : AutoCloseable

The Wayland server: the socket programs connect to, the connected Clients, and the list of Globals — the features the compositor offers (wl_compositor, wl_seat, ...).

val display = Display(loop)
val name = display.addSocket()                 // e.g. "wayland-1"
display.addGlobal(WlCompositor, 6) { compositor -> compositor.requests = ... }
loop.run()

maxForwardedStringBytes
Link copied to clipboard
var maxForwardedStringBytes: Int

The longest text, in UTF-8 bytes, that a program's window title, app id, clipboard type or panel name may have when it is passed on to other programs (panels, docks, clipboard managers): longer ones are cut at a character's end. Programs built on libwayland drop the connection on an event bigger than 4096 bytes. 1024 by default.

privileged
Link copied to clipboard
var privileged: (Client) -> Boolean

Which clients may use the privileged features — screenshots and screen sharing, clipboard managers, panels and lock screens, arranging monitors, gamma, managing other programs' windows. Every client by default (as most compositors do); decide it before clients connect, e.g. by the program behind a client (Client.pid).
