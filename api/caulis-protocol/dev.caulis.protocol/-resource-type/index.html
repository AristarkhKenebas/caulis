ResourceType

abstract class ResourceType<T : Resource>(val name: String, val version: Int)

A Wayland interface, like wl_surface version 7, and a way to create objects of it.

Every generated class has one of these as its companion object, so WlSurface can be used both as a type and as a description: display.addGlobal(WlCompositor, 6) { ... }.
