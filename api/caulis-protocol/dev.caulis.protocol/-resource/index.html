Resource

abstract class Resource(val client: Client, val id: Int, val version: Int)

One protocol object that belongs to one client, for example a client's wl_surface.

Generated subclasses (WlSurface, WlOutput, ...) add the requests the client can send (as a Requests interface the compositor implements) and the events the compositor can send (as sendXxx functions).
