caulis-protocol/dev.caulis.protocol.client/Proxy

Proxy

abstract class Proxy(val connection: Connection, val id: Int, val version: Int)

Our handle to an object that lives in another compositor (the client side of the protocol; Caulis uses it to run as a window inside an existing session).

Generated subclasses add functions for the requests (surface.attach(buffer, 0, 0)) and an Events interface whose functions are called when the compositor sends events.
