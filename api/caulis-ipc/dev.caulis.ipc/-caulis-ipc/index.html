CaulisIpc

class CaulisIpc : AutoCloseable

A connection to a running compositor's IPC socket (see caulis.proto), for programs on the JVM — a bar, a tool, a test:

CaulisIpc.connect().use { ipc ->
    ipc.run("workspace 2")
    println(ipc.state().windowsList.map { it.title })
    ipc.subscribe(EventKind.EVENT_KIND_FOCUS)
    while (true) println(ipc.nextEvent() ?: break)
}
