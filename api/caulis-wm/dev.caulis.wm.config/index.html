object ConfigFile

The configuration as data: config.json in the compositor's folder (written by hand, or by the Nix module) — read, checked against Settings, and applied on top of what the code says. Each setting stands on its own: a mistake in one is reported (with its line) and the others still apply.

interface ConfigLanguage

A language a compositor's configuration can be written in besides Kotlin and JSON — Lua (caulis-lua), Kotlin script (caulis-script), or one of your own. Found through java.util.ServiceLoader: a module on the class path that lists its class in META-INF/services/dev.caulis.wm.config.ConfigLanguage (a public class with a constructor without arguments) is used for its fileName, read after config.json in Caulis.configFolder and followed while running like it.
