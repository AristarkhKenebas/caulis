ConfigFile

object ConfigFile

The configuration as data: config.json in the compositor's folder (written by hand, or by the Nix module) — read, checked against Settings, and applied on top of what the code says. Each setting stands on its own: a mistake in one is reported (with its line) and the others still apply.

fun folder(caulis: Caulis): Path?

The folder caulis's configuration files are read from, as a whole: the user's own (Caulis.configFolder) when any of them is there — then none of the system's is read — else the first of the system's ($XDG_CONFIG_DIRS/<configName>/, /etc/xdg/...: where the NixOS module puts them) that has one. Null: none has any.
