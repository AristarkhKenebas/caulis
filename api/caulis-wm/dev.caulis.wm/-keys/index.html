Keys

class Keys

All the usual keys of a Caulis compositor, each with a name: change one, or turn it off with null. Set them in keys { }:

caulis {
    keys {
        terminal = "Super+T"         // another combination
        close = "Super+Shift+Q"
        dumpState = null             // off
        workspace = "Alt"            // Alt+1..9 instead of Super+1..9
        quit = "Ctrl+Alt+Delete"     // or null: no key quits
    }
    bind("Super+B") { launch("firefox") }  // keys of your own come on top
}

Some keys come as a group: workspace and moveToWorkspace are the modifiers in front of 1..9, move, resize and preselect the ones in front of the arrow keys, consoles the ones in front of F1..F12. Your own Caulis.bind wins over a usual key on the same combination. off turns all of them off but quit and consoles.

A combination is modifiers (Super, Ctrl, Alt, Shift) and a key (a letter, a digit, F1..F24, Return, Tab, Escape, Space, BackSpace, Delete, the arrows Left/Right/Up/Down, Grave, XF86AudioRaiseVolume, ...), written however you like: "Super+Shift+Return", "super shift return", "wIn+Return", or in parts: combo("super", "shift", "return"). A wrong name is reported right where it is set.
