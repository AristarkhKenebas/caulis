Caulis

class Caulis

A complete compositor, configured in a few lines and started with run:

fun main() = caulis {
    layout = Dwindle(Gaps(inner = 8, outer = 12))
    bind("Super+Return") { launch("foot") }
    bind("Super+Q") { closeFocused() }
}
Content copied to clipboard

The same from Java:

Caulis.create()
    .layout(Layouts.Dwindle())
    .bind("Super+Return", c -> c.launch("foot"))
    .run();
Content copied to clipboard

It runs as a window inside the current Wayland session when there is one, and directly on the screen when started from a text console (backend).

Settings are read when it starts; most can also be changed while it runs (each says so). A reload (hotReload, config.json saved again) makes a new configuration: see onStart for what lives through reloads and what belongs to one configuration.
