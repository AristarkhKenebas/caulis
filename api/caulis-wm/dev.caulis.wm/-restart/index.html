Restart

class Restart

When a program of Autostart that ended is started again: never (NEVER, the default), when it crashed (onCrash), whenever it ended (always), or when your own rule says so (whenEnded) — at most maxTimes times within withinMillis (then it is given up, and the log says so).

A crash is any end but a clean one (status 0) and being stopped from outside (Ctrl+C, kill: statuses 130, 137 and 143) — a segfault (139) or an abort (134) count.
