KeyInput

class KeyInput(val evdevCode: Int, val pressed: Boolean, val keysym: String, val modifiers: Int, val modifiersBefore: Int, val locked: Boolean, val timeMillis: Int)

A key as Caulis.onKey gets it, before anything else does: its Linux code, its symbol's name for shortcuts ("h", "H", "Return", "Super_L", "XF86AudioMute" — Latin whatever the layout: the key of "в" on the Russian layout is "d"), and the modifiers held before and after it (Modifiers bits).
