StartupSound

class StartupSound : StartupSettings

A sound when the session starts — off unless you turn it on:

startupSound {
    enabled = true
    preset = "airy"             // or "classic", "glass", "soft" (made by Caulis itself)
    file = "~/sounds/hello.ogg" // or a file of yours instead (ogg, wav, flac: what the player plays)
    volume = 0.8
}
Content copied to clipboard

It is played by a player program (player, else the first of players that works: pw-play, paplay, aplay), never on the compositor's thread, when the desktop fades in (at). The presets are made once and kept in ~/.cache/<configName>/sounds/. The action play-startup-sound plays it again (to try; play-startup-sound glass another preset).
