Autostart

class Autostart : StartupSettings

Programs started with the session — a bar, a tray applet, a notification daemon — one after another (stagger apart, so the start does not stutter), once the desktop is shown (afterReveal):

autostart {
    stagger = 400.milliseconds
    app("waybar")
    app("nm-applet", "--indicator") {
        delay = 2.seconds
        ifNotRunning = true
        restart = OnCrash(maxTimes = 3, within = 1.minutes)
        after("waybar")
    }
    script("~/.config/foo/start.sh")
    shell("sleep 1; notify-send hi")
    desktopEntries = true   // also the .desktop files in ~/.config/autostart
}

They start once per session, the way Caulis.launch starts programs (the session's environment, Wayland first, no input; Caulis.stopProgramsOnQuit ends them with it). A reload never starts them again: it starts only the entries it adds, and stops watching (restarting) the ones it takes away — those keep running. An entry counts as the same when it runs the same command: changing its name, folder, environment or after does not start a second copy (the change applies when it next starts), and an entry taken away and put back by a later reload takes over its program if that still runs. The log area "autostart" tells what was started when; the action autostart (and Caulis.autostartStatus) lists them.
