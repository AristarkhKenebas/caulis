Reveal

class Reveal : StartupSettings

The start, smooth: the screens stay color (black) — no half-drawn frames, no panel popping in — until the compositor is warm: its first frames drawn (shaders compiled on the way) and the work you asked it to wait for done (hold, whenWarm); then the desktop fades in over fade. Never longer than maxWait. Programs of Autostart start after it.

reveal {
    enabled = true
    fade = 600.milliseconds
    maxWait = 4.seconds
    whenWarm("wallpaper") { done -> loadWallpaper(); done() }
}
onReveal { notify("Hello") }
