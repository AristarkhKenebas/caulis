ReloadCompiler

interface ReloadCompiler

Compiles a project's sources inside the running compositor, for Caulis.hotReload — in well under the time a Gradle build takes. The module caulis-reload provides one (meant for development only: add it to the run task, not to what you install); without it, the project's own Gradle compiles.
