class WindowRule

A rule for some windows, written in rule { }: which windows (appId, title, program, where) and what happens to them.

rule {
    appId("spotify")          // which windows (all that are given must fit)
    workspace = 9             // where it opens
    floating = true
    size(900, 600)
    center()
}
rule { title(Regex("Picture.in.Picture")); floating = true; size(480, 270); position(20, 20) }
rule { appId("mpv"); titleBars = TitleBars.NONE; opacity = 1f; margin(-8) }   // a video into the gaps
rule { appId("org.gnome.Calculator"); margin(40) }                         // with room around it
rule { isFloating(); cornerRadius = 16; shadow = true }                     // every floating window, while it floats
rule { appId("mpv"); keepAwake = true; ignore(WindowRequest.MAXIMIZE) }    // the screen stays on
rule { title("Picture-in-Picture"); pinned = true; takesFocus = false }    // on every workspace
rule { appId("org.keepassxc.KeePassXC"); hiddenFromCapture = true }        // black in screen sharing
rule { unless { isXwayland() }; tags("wayland") }                           // tags for other rules
rule { hasTag("wayland"); isFocused(); opacity = 0.95f }

Where and how a window starts (workspace, monitor, floating, size, position, center, maximized, fullscreen, focus) is decided before its first frame; a window that fits only later (programs like Spotify set their title after opening) gets it then, once. Its looks (titleBars, effects, opacity, cornerRadius, border, shadow, blur), its behaviour (minSize, keepAwake, animated, takesFocus, ignore, ...), its tags and its margin follow the rule as long as it fits — also a rule that asks for a state (isFloating, isFocused, ...): it holds while the window is in it. Later rules win over earlier ones where both say something.
