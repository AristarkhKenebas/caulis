Permissions

class Permissions

Which programs may use the features that see or steer more than their own windows — as Hyprland's permissions:

permissions {
    rule("/usr/bin/grim", "screencopy", "allow")       // a path (a regular expression)...
    rule("wl-screenrec", "screencopy", "ask")          // ...or a program's name
    rule(".*", "clipboard", "deny")                     // everything else: no clipboard managers
    default("screencopy", "ask")                        // no rule for a program: ask it
}
Content copied to clipboard

The first rule that matches decides; without one, the feature's default; without that, the privileged rule, as before (everything allowed). "ask" is for "screencopy" (its pictures wait for the answer, see Caulis.askPermission); the other features are decided as a program connects, so they are "allow" or "deny". Asked for each connection, so a change counts for programs started after it.
