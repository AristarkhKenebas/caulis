Plugins

class Plugins

plugins { }: where plugins are, and how much they are forgiven. By default the folder plugins in the configuration's folder is followed; no folder or nothing in it costs next to nothing.

Jar plugins run with your rights and are not sandboxed: installing one is running a program. Lua plugins are sandboxed. See the documentation of plugins.
