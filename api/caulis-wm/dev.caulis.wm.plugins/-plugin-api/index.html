PluginApi

open class PluginApi(val handle: PluginHandle, caulisNow: () -> Caulis)

What a jar plugin gets: every hook of the compositor. All it registers here is taken away when it is disabled, and all its callbacks are guarded: what one throws disables the plugin with a notice, and one that holds up the compositor's thread is reported. Everything else is reachable through caulis and desktop, as in a configuration; what you register there yourself goes into scope (each such call returns something closable) or stays behind.

It all runs on the compositor's thread (from another: post), and survives reloads of the configuration.
