KotlinScriptConfig

class KotlinScriptConfig : ConfigLanguage

config.kts: the configuration as a Kotlin script. It is compiled by a Java of its own (a short-lived process: the Kotlin compiler, hundreds of megabytes once loaded, never stays in the compositor), the first time and after each change — a few seconds; the compiled script is kept in ~/.cache/<configName>/config-kts (the newest Caulis.compiledScriptsKept versions), so starting again only loads it: no compiler at all.

A ConfigLanguage: Caulis finds it by itself when caulis-script is on the class path — there is nothing to call. The compiler process's Java options and time limit: compilerJvmOptions, compilerTimeoutSeconds.
