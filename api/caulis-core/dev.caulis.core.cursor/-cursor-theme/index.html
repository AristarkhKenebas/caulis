CursorTheme

class CursorTheme

A cursor theme (Adwaita, Bibata, Breeze, ...) at a size in pixels. Cursors are asked for by the names programs use (default, pointer, text, nwse-resize, ... the CSS names); older themes that only know the X11 names (left_ptr, hand2, xterm, ...) work too. A cursor the theme does not have comes from the themes it inherits, then the system's.
