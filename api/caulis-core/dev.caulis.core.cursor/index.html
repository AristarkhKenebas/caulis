CursorTheme
Link copied to clipboard
class CursorTheme

A cursor theme (Adwaita, Bibata, Breeze, ...) at a size in pixels. Cursors are asked for by the names programs use (default, pointer, text, nwse-resize, ... the CSS names); older themes that only know the X11 names (left_ptr, hand2, xterm, ...) work too. A cursor the theme does not have comes from the themes it inherits, then the system's.

CursorThemeProvider

interface CursorThemeProvider

Cursor themes that come with a library instead of being installed. A library offers its themes by listing its provider in META-INF/services/dev.caulis.core.cursor.CursorThemeProvider; adding the library to a project is then enough.

XCursor

object XCursor

Reads cursor files in the Xcursor format, the one all Linux cursor themes use (the files in /usr/share/icons/<theme>/cursors/). A file holds the cursor in several sizes, and animated cursors several frames per size.
