DBusConnection

class DBusConnection : AutoCloseable

A small client (and server) of D-Bus — the system bus (logind: sleep, brightness, the session's lock) or the session bus — on the compositor's event loop: no thread, no library. Enough of the wire format for what a compositor asks: the basic types, arrays, structs, file descriptors.

DBusScope
Link copied to clipboard
class DBusScope(val connection: DBusConnection) : AutoCloseable

A DBusConnection as one part of a program uses it: what it exports and the signals it listens to are remembered, and close takes them all away — the connection itself stays open for the others. A compositor's configuration gets one, so a reload does not leave the old configuration's objects and listeners behind.
