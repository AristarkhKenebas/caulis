DBusConnection

class DBusConnection : AutoCloseable

A small client (and server) of D-Bus — the system bus (logind: sleep, brightness, the session's lock) or the session bus — on the compositor's event loop: no thread, no library. Enough of the wire format for what a compositor asks: the basic types, arrays, structs, file descriptors.
