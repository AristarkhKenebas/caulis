DrmOutput

class DrmOutput : AutoCloseable

One monitor driven by Caulis: a connector (the socket the cable is in), a CRTC (the part of the GPU that sends pictures to it) and its primary plane (the full-screen layer).

Pictures are drawn into one of two buffers and then shown with a page flip; when the monitor has started showing it, onFrame asks for the next one. The monitor's rhythm (60, 144, ... Hz) paces everything.

present
Link copied to clipboard
fun present(draw: (target: GpuTarget, age: Int) -> Unit): Boolean

Draws the next picture with draw and sends it to the monitor. draw also gets how many frames old the buffer's picture is (1 = previous frame, 0 = unknown: draw everything). Does nothing while another virtual terminal is shown, the screen is off or a picture is still on its way. Returns true if a picture was drawn and sent.

Shows a program's own GPU buffer directly, without drawing anything (for a fullscreen game or video). The kernel checks first whether the display can show it; returns false if not — then draw normally with present. The program gets the buffer back when the monitor has moved on to the next picture.
