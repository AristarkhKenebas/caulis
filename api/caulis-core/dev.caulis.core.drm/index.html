DrmDevice

class DrmDevice(loop: EventLoop, session: Session, val path: Path) : AutoCloseable

One GPU's display side (a DRM "card" device, e.g. /dev/dri/card0), opened through the session. It talks to the kernel with atomic mode setting: every change to the screens is one all-or-nothing request that can be tested first, so a monitor never ends up half-configured.
