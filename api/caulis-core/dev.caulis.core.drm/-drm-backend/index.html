DrmBackend

class DrmBackend : AutoCloseable

Running directly on the screen (no other compositor): the login session, the GPU's display side (device), monitors (outputs) and input devices (input).

Monitors can be plugged in and out at any time (onOutputAdded, onOutputRemoved); switching to another virtual terminal and back is handled here (everything pauses and then comes back with a full redraw).

DrmBackend.open(loop).use { backend ->
    backend.onOutputAdded = { output -> output.onFrame = { output.present { target -> ... } } }
    backend.start()
    loop.run()
}
