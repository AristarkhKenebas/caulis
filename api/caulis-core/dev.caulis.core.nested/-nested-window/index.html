NestedWindow

class NestedWindow(loop: EventLoop, renderer: Renderer, title: String = "Caulis", appId: String = "dev.caulis.Nested", outerSocket: Path? = null) : AutoCloseable

Caulis's window inside an existing Wayland session (the "nested" backend).

Frames are drawn with renderer and handed to the outer compositor without copying (GPU buffers through linux-dmabuf) when it supports that on the same GPU; otherwise they are copied through shared memory. Frames are paced by the outer compositor: onFrame is called when it is a good moment to draw the next one.
