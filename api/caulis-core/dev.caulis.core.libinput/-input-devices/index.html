InputDevices

class InputDevices(loop: EventLoop, session: Session) : AutoCloseable

Keyboards, mice, touchpads, touch screens and drawing tablets (through libinput), opened via the session.

Devices come and go at any time. When one disappears while keys or buttons on it are held down, they are reported as released, so nothing stays "stuck" (a pulled-out keyboard with Ctrl held must not leave Ctrl pressed forever) — a pen near a tablet that goes is lifted and taken away.

ownThread
Link copied to clipboard
var ownThread: Boolean

Input read on a thread of its own ("caulis-input"), not on the compositor's: libinput's events are read and turned into Caulis's there and queued for the compositor's thread, which handles them in the same order. A busy moment of the compositor's thread then holds no input back in the kernel, and the cursor (on a cursor plane) still moves: earlyPointer is told of each movement on that thread. All of libinput is used on that thread only (device settings too); opening a device asks the compositor's thread (the session). False: everything on the compositor's thread, as before.
