EarlyPointer
Link copied to clipboard
interface EarlyPointer

Told of the pointer's movement on the input thread, before the compositor's thread handles it (InputDevices.ownThread): the cursor can move at once even while the compositor's thread is busy. Desktop.earlyPointer is one: it moves the cursor plane. All three are called by InputDevices; another backend reading input on a thread of its own may call them the same way.

ShortcutsInhibit

class ShortcutsInhibit(display: Display, seat: Seat)

keyboard-shortcuts-inhibit: a window that wants every key for itself — a compositor running in a window (one you are making), a virtual machine, a remote desktop — asks for it.
