TabletAxes

data class TabletAxes @JvmOverloads constructor(val pressure: Double? = null, val distance: Double? = null, val tiltX: Double? = null, val tiltY: Double? = null, val rotation: Double? = null, val slider: Double? = null, val wheelDegrees: Double = 0.0, val wheelClicks: Int = 0)

What a tool tells besides its place, each null when it did not change (or the tool cannot tell it): pressure 0..1, distance above the tablet 0..1, tiltX and tiltY in degrees from upright (positive: towards the right and towards the user), rotation in degrees (clockwise), slider -1..1 (an airbrush's finger wheel), and a turn of a tablet mouse's wheelDegrees in wheelClicks.
