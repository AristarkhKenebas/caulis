TabletTool

class TabletTool @JvmOverloads constructor(val type: TabletTool.Type, val capabilities: Set<TabletTool.Capability> = emptySet(), val serial: Long = 0, val hardwareId: Long = 0)

A tool used on a tablet: a pen, its eraser end, an airbrush, a tablet mouse, ... serial tells two pens of the same kind apart (0: it cannot), hardwareId is the maker's id for the kind of tool (0: unknown). Tools are compared by identity: use the same object for the same physical tool.
