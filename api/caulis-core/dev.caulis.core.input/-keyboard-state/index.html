KeyboardState

class KeyboardState : AutoCloseable

Which keys and modifiers are pressed right now.

Key codes here are Linux input codes (evdev), as libinput and Wayland use them; xkbcommon wants them plus 8, which this class adds.

fun shortcutSymbol(evdevCode: Int, layoutCount: Int): Int

The symbol a key means for shortcuts: a Latin letter of the layout in use as it is; else for a printing key what it gives in the first layout where it is Latin — so Super+D is Super+D on the Russian layout too (where the key types "в"), and Super+/ is Super+/ (where it types "."). Keys like F1, Return and the arrows are as they are.
