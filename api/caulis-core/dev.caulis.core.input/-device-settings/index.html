DeviceSettings

class DeviceSettings

How a mouse, trackball, touchpad or drawing tablet behaves. Every setting is null by default: then the device (and libinput) choose — except tapping on touchpads, which Caulis turns on, and the tablet settings, whose defaults each one says.
