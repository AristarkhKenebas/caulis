Scroll

class Scroll(val source: Scroll.Source, val horizontal: Double = 0.0, val vertical: Double = 0.0, val horizontal120: Int = 0, val vertical120: Int = 0, val stopsHorizontal: Boolean = false, val stopsVertical: Boolean = false, val inverted: Boolean = false)

One scroll: what the wheel or the fingers did at one moment, both directions together (a diagonal swipe on a touchpad is one scroll, and programs get it as one).

horizontal and vertical are the distance in pixels (positive: right and down). horizontal120 and vertical120 are the wheel's notches in 1/120 (a full notch is 120, high-resolution wheels send parts of one); 0 for fingers. stopsHorizontal and stopsVertical say the fingers stopped on that direction (programs end their kinetic scrolling then). inverted is true with natural scrolling: the content follows the fingers, so the scroll goes the other way than the fingers moved.
