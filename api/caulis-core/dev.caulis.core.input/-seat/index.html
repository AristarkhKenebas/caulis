Seat

class Seat(display: Display, keymap: Keymap) : AutoCloseable

wl_seat: one keyboard and one pointer, as clients see them.

The compositor decides who gets input (focusKeyboard, pointerMotion); this class turns that into the right events for the right client: enter/leave when focus moves, keys and modifiers, motion, buttons and scrolling.

The key of KeyBindings combinations evdevCode stands for now, for KeyBindings.keyOf: a key that types a Latin letter, digit or punctuation mark (see shortcutName: on the Russian layout what it types in the first Latin layout) is the key of that name in KeyBindings — on a German keyboard the key printed Z is Super+Z's — and every other key (F1, Return, the arrows, é) is itself.
