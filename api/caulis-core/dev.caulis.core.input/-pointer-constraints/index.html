PointerConstraints

class PointerConstraints(display: Display, seat: Seat)

pointer-constraints and relative-pointer: games and 3D programs (Blender) hold the pointer in place (locked: only its movement counts) or inside their window (confined), and get the mouse's movement itself, also where the pointer cannot go further. A constraint works while its window has the keyboard and the pointer is over it.
