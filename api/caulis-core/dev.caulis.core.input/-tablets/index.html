Tablets

class Tablets(display: Display, seat: Seat)

zwp_tablet_manager_v2 (tablet-v2): drawing programs (Krita, GIMP, Inkscape, Xwayland's X11 programs) get the pen as a pen — pressure, tilt, distance, rotation, the eraser end — instead of as the pointer.

Every program that asks is told about the tablets there are (add), the tools used on them so far, and the pads. Which program gets the pen is the desktop's choice (dev.caulis.core.Desktop.tabletMotion and the rest: the one under it, unless the pen is the pointer there); the pads go to the program with the keyboard.
