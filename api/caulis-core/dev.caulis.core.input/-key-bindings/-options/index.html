Options

data class Options(val repeat: Boolean = false, val release: Boolean = false, val whileLocked: Boolean = false, val description: String? = null)

How a combination behaves: repeat while held (volume keys), runs on release instead of on the press, works whileLocked (the compositor decides that), and description says what it does (for lists of keys).
