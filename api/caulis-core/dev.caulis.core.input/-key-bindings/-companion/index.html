The modifiers and key code of combination — written however people write it: "Super+Shift+Q", "super shift q", "wIn+S", "Q+Super", "mod4+Return", "Super+Й" (the same key as Super+Q). Throws with a plain message (and a guess at what was meant) when a name is unknown.
