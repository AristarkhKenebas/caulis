KeyBindings

class KeyBindings

Key combinations of the compositor itself, written the way people say them (case, spaces and the order do not matter, see parse):

val keys = KeyBindings()
keys.bind("Super+Return") { launch("foot") }
keys.bind("Ctrl+Alt+BackSpace") { quit() }
keys.bind("Alt+Tab") { desktop.cycleFocus() }
Content copied to clipboard

Feed every key press and release to key; it returns true when a combination was used. Such keys are not passed to programs — neither the press nor its release.

Keys are physical (Linux key codes), so combinations work the same with every keyboard layout (Super+Q stays on the same key with a Russian layout). Mouse buttons ("Super+MouseSide", "mouse:276"), the wheel ("Super+WheelUp") and a drawing tablet's pad buttons ("Pad1", the first) are keys too, and a modifier alone ("Super") is a tap of it: pressed and let go with nothing else in between.

fun forget(evdevCode: Int)
