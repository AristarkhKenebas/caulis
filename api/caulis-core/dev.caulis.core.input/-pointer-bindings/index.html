PointerBindings

class PointerBindings

What the mouse's buttons and wheels do, apart from the keyboard's combinations: any button (by its name or Linux code, KeyBindings.parse: "Super+MouseSide", "BTN_TASK", "mouse:0x115"), and the wheel in all four ways ("Super+WheelLeft": a side wheel), with any modifiers.

val mouse = PointerBindings()
mouse.press("Super+WheelRight", PointerBindings.Options(cooldownMillis = 150)) { nextWorkspace() }
mouse.press("MouseSide", PointerBindings.Options(pass = true)) { log("back") }     // the program gets it too
mouse.click("MouseMiddle") { overview() }
mouse.longPress("MouseMiddle", 500) { launcher() }
mouse.gesture("Super+MouseExtra", mapOf(PointerBindings.Direction.LEFT to { previous() }, PointerBindings.Direction.RIGHT to { next() }))

A button can have several of these at once. Feed it button, scroll and motion; each returns true when the event is taken (do not pass it on). A press and its release always go the same way: a press given to a program is let go for that program too, whatever modifiers changed in between. It knows nothing of windows or a seat, and holds no secrets: it logs nothing.

The modifiers are the caller's, usually KeyBindings.heldModifiers; they must match exactly, as for key combinations (Super+Shift+button is not Super+button).

How a binding behaves: pass the press and the release on to the program under the pointer as well (false: taken, the program never hears of it); works whileLocked (false: behind a lock screen it does not exist); runs at most once per cooldownMillis (0: always; a side wheel spins fast); description says what it does (for lists of keys).
