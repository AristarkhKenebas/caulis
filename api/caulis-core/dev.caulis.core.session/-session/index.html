Session

class Session : AutoCloseable

The login session on this seat (through libseat: seatd or systemd-logind).

It opens the GPU and input devices for us (no root needed) and tells us when the user switches to another virtual terminal (active becomes false: stop drawing, let go of the devices) and back (true: take over again, redraw everything).
