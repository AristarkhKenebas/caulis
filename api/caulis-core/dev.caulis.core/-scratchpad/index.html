Scratchpad

class Scratchpad

A special workspace: windows that are shown and hidden with one key, above whatever workspace is on screen (a drop-down terminal, a music player, a notes window, ...). Create them with Desktop.addScratchpad; windows join when they match match.

A compact window that slides in from a screen edge — like a drop-down terminal. depth is how far it reaches into the screen, length how much of the edge it covers (centred), both as shares of the screen; margin keeps it off the edge.
