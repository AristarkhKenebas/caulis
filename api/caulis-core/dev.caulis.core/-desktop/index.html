Desktop

class Desktop(val renderer: Renderer, seat: Seat, compositor: Compositor, screenWidth: Int, screenHeight: Int) : XdgShell.Listener, LayerShell.Listener, SessionLockManager.Listener, AutoCloseable

The window manager: workspaces, layouts (floating or tiled — see Layout), focus, maximize/fullscreen/minimize, moving and resizing with the pointer, popups. It also draws everything — only the parts that changed (see DesktopView).

frameShown
Link copied to clipboard
fun frameShown(timeMillis: Int)

Tells every program on screen (and those kept updating) that its last frame was shown, so it can draw the next one. Called at every refresh, also when nothing had to be redrawn.
