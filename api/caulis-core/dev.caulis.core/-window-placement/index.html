WindowPlacement

data class WindowPlacement @JvmOverloads constructor(val workspace: Int? = null, val monitor: String? = null, val floating: Boolean? = null, val width: Int? = null, val height: Int? = null, val x: Int? = null, val y: Int? = null, val center: Boolean = false, val maximized: Boolean? = null, val fullscreen: Boolean? = null, val goToWorkspace: Boolean = false, val focus: Boolean = true, val pinned: Boolean? = null, val specialWorkspace: String? = null)

Where a new window goes and how it starts, decided before its first frame (so it never shows up somewhere else first): see Desktop.placementFor. Null means "as usual". Sizes and positions are in desktop units; a position is from the top left corner of the monitor's free area (inside panels).
