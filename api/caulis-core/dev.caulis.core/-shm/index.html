Shm

class Shm(display: Display)

wl_shm: clients draw into shared memory and hand it to the compositor as buffers.

Everything a client says about that memory is checked: offsets, sizes and strides must stay inside the memory it actually shared (computed in Long, so huge numbers cannot wrap around), and the memory itself is mapped safely (SharedMemory).

var maxBufferSide: Int

The widest and tallest picture a program may share, in pixels (16384 by default, what GPUs show at most). A bigger one is refused when the program makes it (it would cost gigabytes to copy, and no GPU could show it); set it to your GPU's limit if it is lower.
