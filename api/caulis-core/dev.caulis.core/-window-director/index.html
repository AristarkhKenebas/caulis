WindowDirector

interface WindowDirector

A compositor that places windows itself, every frame (as wlroots compositors do with their own scene): Desktop.director. The windows it manages are left out of the layouts, get no animations of the desktop's own and are drawn where place says — stretched, faded, clipped, in their own order. Everything else stays the desktop's: focus and keys, menus (popups follow their window), panels, the lock screen, X11 programs, effects (borders, shadows, blur) and frame timing.

desktop.director = object : WindowDirector {
    override fun place(window: Window, now: Long): WindowPlace? =
        WindowPlace(100.0, 80.0, 640.0, 400.0, cornerRadius = 12f)
}

All of it runs on the compositor's thread, place once per frame for every window: keep it quick. If it fails, that is logged and the window stays where it was shown last.
