Monitor

class Monitor

One monitor: the part of the desktop it shows. All monitors together make one desktop in desktop units (area is this monitor's part of it); each has its own scale (how many of its pixels one unit is), its own panels, and shows one workspace (see Desktop.workspaceMode).

Get them from Desktop.monitors; the backend adds and removes them with Desktop.addMonitor and Desktop.removeMonitor.
