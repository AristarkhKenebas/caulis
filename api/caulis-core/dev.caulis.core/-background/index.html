Background

sealed class Background

What the desktop shows behind everything: a colour, a gradient, a picture, your own drawing, or a shader — still or moving. Set it with Desktop.background (or a different one per monitor and workspace with Desktop.backgroundFor).

A wallpaper program (swaybg, hyprpaper, swww, mpvpaper, ... — anything on the background layer) draws on top of this and wins: both can be there, nothing conflicts.

Background.color(Color.hex("#1e1e2e"))
Background.gradient(Color.hex("#1e3c72"), Color.hex("#2a5298"))
Background.image(Path.of("/usr/share/backgrounds/forest.jpg"))
Background.shader(WallpaperShader("vec4 wallpaper(vec2 at) { return vec4(at, 0.5 + 0.5 * sin(time), 1.0); }"))
Background.painted { g, look -> g.fillOval(0, 0, look.width, look.height) }

Image

data class Image(val path: Path, val fit: Background.Fit = Fit.FILL, val behind: Color = Color(0f, 0f, 0f), val span: Boolean = false) : Background

A picture from a file (PNG, JPEG, BMP or GIF), fitted as fit says; behind shows where it does not cover the monitor. Read in the background: until it is, behind. With span, one picture over all monitors together, each showing its part (in desktop units: it goes on seamlessly from one to the next, whatever their scales).
