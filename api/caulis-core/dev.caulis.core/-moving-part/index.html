MovingPart

class MovingPart @JvmOverloads constructor(val id: Int, val x: Double, val y: Double, val width: Double, val height: Double, val kind: Int = 0, val data: FloatArray = NONE, val alpha: Float = 1.0f, val kept: Boolean = false, val keptScale: Float = 1.0f)

A small thing moving over a WallpaperShader's picture (MovingParts). id says which one it is from frame to frame; x, y its top left, width, height its size, 0..1 of the picture (it may stick out). Nothing is drawn anew for one that is the same as in the frame before.

Drawn each time it changes, blended over the kept picture, by the shader itself with movingPart = kind (else -1: the kept picture), movingBox its place (at units), and movingData, movingMore the numbers of data (up to 8). Only its own pixels pay: the shader returns it alone, premultiplied (alpha 0 with a colour: light added).

With kept, the shader draws it only once, into a small picture of its own keptScale as sharp, at 0..1 over that picture: after that it costs only moving and blending that one, at any place, also between pixels, and alpha. Leave a pixel or two empty along its edge. It is drawn again when data changes.
