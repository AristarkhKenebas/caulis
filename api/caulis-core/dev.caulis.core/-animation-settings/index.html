AnimationSettings

class AnimationSettings @JvmOverloads constructor(val tree: AnimationTree, val enabled: Boolean = false, val millis: Long = 220, val curve: Curve = Curve.EASE_OUT, val entries: Map<String, AnimationEntry> = emptyMap())

Hyprland-like animation settings for an AnimationTree: a global switch (enabled), a global time (millis) and curve, and settings by name (entries) for parts of the tree. Caulis' own are in Animations; a compositor on Caulis keeps one of these for its own.

What an animation comes to (resolve): for each of on/off, time, curve and look, its own entry; else the nearest entry above it that says; else the animation's usual (what code gives, or AnimationNode.millis/AnimationNode.curve); else the global one. An entry's enabled = true turns an animation on even while enabled is false: one line is enough to have just that one.
