ServerDecorations

class ServerDecorations(display: Display, desktop: ServerDecorations.Listener)

Agrees with programs who draws their title bars: xdg-decoration (Qt, Chromium, Electron, mpv, foot, ...) and the KDE protocol (GTK 3, older Qt). desktop decides by its settings; programs that use neither always draw their own.
