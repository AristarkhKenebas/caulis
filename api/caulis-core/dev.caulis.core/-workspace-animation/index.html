WorkspaceAnimation

fun interface WorkspaceAnimation

How a workspace change looks on one monitor: given how far along it is (0 to 1, through the curve), the direction (1: to a higher number, -1: back) and the monitor, where the new and the old workspace are drawn (moved by dx, dy units) and how strongly.
