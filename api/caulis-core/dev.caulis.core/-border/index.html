Border

data class Border @JvmOverloads constructor(val width: Int = 2, val focused: Paint = Paint.solid(Color.hex("#89b4fa")), val unfocused: Paint = Paint.solid(Color.hex("#45475a")), val urgent: Paint? = null, val groupedFocused: Paint? = null, val groupedUnfocused: Paint? = null, val animate: Boolean = true)

A frame width pixels wide around a window, filled by whether it has the focus: one colour, a gradient, a turning gradient or a shader (Paint) — like Hyprland's col.active_border, col.inactive_border, col.urgent and the group borders:

Border(3, focused = Paint.parse("rgba(33ccffee) rgba(00ff99ee) 45deg"), unfocused = Paint.parse("rgba(595959aa)"))
Border(3, focused = Paints.file(Path.of("glow.glsl"))).withUrgent(Paint.solid(Color.hex("#ff5555")))
Content copied to clipboard

A shader paint learns the window's state (focused, urgent, grouped, see dev.caulis.render.Paint.Shader), so one shader can serve every state.
