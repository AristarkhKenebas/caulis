SpecialWorkspaces

data class SpecialWorkspaces @JvmOverloads constructor(val dim: Float = 0.4f, val blur: Blur? = null, val gap: Int = 40, val size: Double = 1.0, val animation: String = "scratchpads", val hideWhenEmpty: Boolean = true, val newWindowsJoin: Boolean = true, val hideOnLock: Boolean = true, val clickOutsideHides: Boolean = true, val layout: Layout? = null, val look: SpecialLook = SpecialLook())

How special workspaces look and behave (Desktop.specialWorkspaces) — Hyprland's special workspaces: named workspaces that appear over the current one on the focused monitor, everything behind them dimmed (and blurred), with tiling inside.

desktop.toggleSpecialWorkspace()                         // "special", Hyprland's togglespecialworkspace
desktop.toggleSpecialWorkspace("music")
desktop.moveToSpecialWorkspace(window, "music", silent = true)
desktop.moveOutOfSpecialWorkspace(window)                // back to the workspace on screen
desktop.specialWorkspaces = SpecialWorkspaces(dim = 0.5f, blur = Blur(6, 3), gap = 60)

Special workspaces and scratchpads (Desktop.addScratchpad) share their machinery: a scratchpad is made for one app summoned by a key (its rule says which windows are its own, its key starts the program); a special workspace is a whole workspace layer — any window can be moved in and out, it tiles them with the compositor's layout, it is made the first time it is named. Only one special workspace is shown on a monitor at a time (showing another one hides it), as in Hyprland.
