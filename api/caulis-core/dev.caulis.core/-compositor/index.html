Compositor

class Compositor(val display: Display, renderer: Renderer?)

wl_compositor and wl_subcompositor: clients create surfaces (the things that become windows, menus, cursors) and attach surfaces to each other (subsurfaces).

With a renderer, every committed picture is copied to the GPU at once, so the client gets its buffer back immediately. Without one (in tests) pictures are ignored.
