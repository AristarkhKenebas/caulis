Effects

data class Effects @JvmOverloads constructor(val cornerRadius: Int = 0, val border: Border? = null, val shadow: Shadow? = null, val blur: Blur? = null, val opacity: Float = 1.0f, val inactiveOpacity: Float = opacity, val inactiveShadow: Shadow? = null, val focusChangeMillis: Long = 150, val dimInactive: Float = 0.0f)

How windows (or panels) look beyond their own picture: rounded corners, a border, a shadow, frosted-glass blur behind see-through parts, and transparency. Everything is off in NONE; switch on what you like:

desktop.effects = Effects(
    cornerRadius = 10,
    border = Border(width = 2, focused = Color.hex("#89b4fa"), unfocused = Color.hex("#45475a")),
    shadow = Shadow(),
    blur = Blur(),
    inactiveOpacity = 0.92f,
)

Borders and shadows can be gradients, turning gradients or shaders of your own (Paint):

border = Border(width = 3, focused = Paint.conic(Color.hex("#33ccff"), Color.hex("#00ff99"), turnsPerSecond = 0.2)),
shadow = Shadow(softness = 30, color = Paint.solid(Color.hex("#89b4fa80")), offsetY = 0),   // a glow
inactiveShadow = Shadow(softness = 12, offsetY = 3),   // smaller when not focused (Shadow.NONE: none)
Content copied to clipboard

When the focus moves, borders and shadows change over focusChangeMillis.

Blur only shows behind see-through windows (a transparent terminal, or with an opacity below 1). Fullscreen windows never get effects.
