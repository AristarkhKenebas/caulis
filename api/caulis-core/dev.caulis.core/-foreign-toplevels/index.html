ForeignToplevels

class ForeignToplevels(display: Display, desktop: Desktop)

The window list for docks and taskbars (Waybar's taskbar, nwg-dock, sfwbar, a dock of your own, ...):

  • wlr-foreign-toplevel-management: every window with its title, app id and state; the dock can activate, minimize, maximize, make fullscreen and close them, and tell where its icon for a window is, so the window minimizes into that icon.

  • ext-foreign-toplevel-list: the same list, only to read (newer tools use it).

Whenever the windows change, each dock is told exactly what changed for each window.
