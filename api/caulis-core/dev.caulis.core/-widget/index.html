Widget

interface Widget

A part of the compositor's own interface — a bar, a dock, a volume pill, a launcher, a notification — drawn by your code and getting the pointer where it is, and the keyboard when it asks (Desktop.addWidget). Unlike an Overlay it takes nothing from the programs elsewhere; unlike a Drawing it gets input. Coordinates it is told are its own (0, 0 at the top left of area).

caulis-compose makes one from Compose; anything else that draws pictures works too.

showsWhileLocked
Link copied to clipboard
open val showsWhileLocked: Boolean

True if it is shown and gets input while the session is locked (an on-screen keyboard, a "battery low" pill). False by default: behind a locker program it is not drawn, and behind the compositor's own lock screen (Desktop.lockInternally) it is drawn but gets nothing. The widget given to Desktop.lockInternally needs no such mark.

True if a click gives it the keyboard (a text field, a launcher). It keeps it until Desktop.focusWidget (null) or a click elsewhere.
