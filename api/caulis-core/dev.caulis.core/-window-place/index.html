WindowPlace

data class WindowPlace @JvmOverloads constructor(val x: Double, val y: Double, val width: Double, val height: Double, val alpha: Float = 1.0f, val cornerRadius: Float? = null, val clip: Rect? = null, val z: Double = 0.0, val takesInput: Boolean = true)

Where and how a window is shown at one moment, as your compositor decides it (see WindowDirector): x, y, width, height on the desktop, in units — fractions too. When that is not the window's own size its picture is stretched into it (zoomed out, half way through an animation); the size the program draws at is yours to ask for with Window.configure.
