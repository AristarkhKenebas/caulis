FixedMovingParts

data class FixedMovingParts @JvmOverloads constructor(val areas: List<List<Double>>, val framesPerSecond: Int = 10, val every: Int = 1, val keptSeconds: Double = 600.0, val settleSeconds: Double = 0.3, val maxKeptSize: Double = 2.0) : MovingParts

Parts that stay in their places (areas: x, y, width, height, 0..1 of the picture): each is drawn by the shader with movingPart its number and movingData.x its time, rounded so that one part in every changes per frame at framesPerSecond (so one changes framesPerSecond / every times a second). For a configuration that names only numbers.
