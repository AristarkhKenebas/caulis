Animations

data class Animations @JvmOverloads constructor(val windowOpen: WindowAnimation = WindowAnimation.pop(), val windowClose: WindowAnimation = WindowAnimation.pop(), val windowMove: WindowAnimation = WindowAnimation.move(), val minimize: WindowAnimation = WindowAnimation.genie(), val restore: WindowAnimation = WindowAnimation.genie(), val workspaceSwitch: WorkspaceAnimation = WorkspaceAnimation.SLIDE, val overviewMillis: Long? = null, val curve: Curve = Curve.EASE_OUT, val scaleChangeMillis: Long = 250, val enabled: Boolean = false, val entries: Map<String, AnimationEntry> = emptyMap())

All of the compositor's animations, Hyprland-like: a global switch (enabled, off by default: everything changes at once), named animations in a tree (AnimationTree.CAULIS: windows → windowsIn, windowsOut, windowsMove, scratchpads, minimize, restore; workspaces; overview; border; screenshot; fade → fadeScale, fadeBackground, fadeNotices, fadeOsd) with settings by name (entries: on/off, time, curve, look), and the looks themselves as code (WindowAnimation, WorkspaceAnimation). Times are Desktop.animationMillis unless an animation has its own.

Animations(enabled = true)                                        // the usual, on
Animations(enabled = true, minimize = WindowAnimation.genie())    // macOS's genie
Animations(enabled = true, windowOpen = WindowAnimation.fade() + WindowAnimation.slide(dy = 80),
           workspaceSwitch = WorkspaceAnimation.SLIDE_VERTICAL.lasting(300))
Animations(enabled = true)
    .with("windows", millis = 300, curve = Curve.bezier(0.05, 0.9, 0.1, 1.05))
    .with("windowsIn", style = "popin 80%")
    .with("fade", enabled = false)
Animations().with("workspaces", enabled = true)                   // just this one
Animations.NONE                                                   // nothing moves
