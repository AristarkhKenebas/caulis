Output

class Output(display: Display, val name: String, val description: String, width: Int, height: Int, val refreshMillihertz: Int, scale: Double = 1.0, val physicalWidthMm: Int = 0, val physicalHeightMm: Int = 0, val make: String = "Caulis", val model: String = name)

wl_output: tells clients about one monitor — its size, refresh rate and scale. The size can change (e.g. Caulis's window in nested mode is resized).
