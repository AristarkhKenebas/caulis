FrameStats

class FrameStats(name: String, intervalNanos: Long, print: (String) -> Unit = ::println) : AutoCloseable

Measures how smoothly one screen runs and prints a summary every few seconds:

eDP-1: 143.8 fps | draw 0.21 ms avg, 0.80 max | late 0 | GC pauses 2, longest 0.04 ms
Content copied to clipboard

  • draw: time spent preparing a frame (CPU side);

  • late: frames that reached the screen one or more refreshes later than they could have (each one is a visible stutter);

  • GC pauses: moments the garbage collector stopped the program (should be well under a millisecond with ZGC).

Call drawStarted / drawFinished around drawing and presented when the frame is on screen. Measuring itself costs almost nothing, so it can stay on.
