NoticeStyle

data class NoticeStyle @JvmOverloads constructor(val placement: NoticePlacement = NoticePlacement.Banner(), val font: String = java.awt.Font.SANS_SERIF, val fontSize: Int = 13, val padding: Int = 10, val gap: Int = 8, val radius: Int = 10, val info: NoticeColors = NoticeColors(Color.hex("#2b2f38"), Color.hex("#e8eaee")), val warning: NoticeColors = NoticeColors(Color.hex("#f5c211"), Color.hex("#1b1b1b")), val error: NoticeColors = NoticeColors(Color.hex("#e01b24"), Color.hex("#ffffff")), val infoSeconds: Double = 5.0, val warningSeconds: Double = 12.0, val errorSeconds: Double = 0.0, val maxShown: Int = 4, val fadeMillis: Long = 180, val everyMonitor: Boolean = false, val painter: NoticePainter = DefaultNoticePainter)

How the compositor's notices look and where they are. Sizes are in desktop units (scaled like everything); for a look of your own, give a painter.

NoticeStyle()                                                        // a strip at the top that pushes windows down
NoticeStyle(placement = NoticePlacement.Toast())                     // cards at the bottom right
NoticeStyle(placement = NoticePlacement.Banner(room = Room.COVER))   // a strip over everything
