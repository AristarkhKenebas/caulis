Activation

class Activation(display: Display, seat: Seat, desktop: Activation.Listener)

xdg-activation: a window asks for the focus — a link clicked in a chat opens the browser and brings it forward, a second start of a program brings the first one. A request with a good token (asked for by the program that had the keyboard, or given by the compositor to a program it starts) gets the focus, even on another workspace; any other one only marks the window as wanting attention (Window.urgent), so nothing steals the focus.

dialogsTakingFocusBackAreModal

var dialogsTakingFocusBackAreModal: Boolean

A dialog that takes the focus back from its window within modalDialogWithinMillis of that window getting it becomes modal: its window hands it the focus from now on, instead of the two taking it in turns (a flickering border). JetBrains' IDEs and other Java programs open such dialogs without saying they are modal. On by default; false turns this guess off (only dialogs that say so are modal).

tokensNeedFocus
Link copied to clipboard
var tokensNeedFocus: Boolean

A token a program asked for (to hand to the program it opens: a link clicked in a chat) is good only while that program still has the keyboard (true, the default): one that asked while it had it cannot take the focus later, after you moved on — up to tokenLifetimeMillis — and its window is only marked urgent then. False: good for the whole tokenLifetimeMillis. Tokens the compositor gives programs it starts are not affected.
