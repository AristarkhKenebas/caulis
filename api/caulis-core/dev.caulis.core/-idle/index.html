Idle

class Idle(display: Display, loop: EventLoop, desktop: Desktop)

When nobody uses the computer: programs (watch, and swayidle or hypridle through ext-idle-notify) are told after so long without a key, a click or the pointer moving, and again when someone is back. A video player that keeps a window on screen (idle-inhibit), a hold (a browser asking over D-Bus), inhibitedByUser, or — if fullscreenInhibits — a fullscreen window keeps it from counting as idle. Something that starts keeping it awake while it is idle already (a video started by itself) counts as someone back.

hold
Link copied to clipboard
fun hold(reason: String, pid: Int = 0): AutoCloseable

Keeps the computer from counting as idle until the result is closed — for what asks outside Wayland (org.freedesktop.ScreenSaver.Inhibit over D-Bus, logind's idle inhibitors). reason is shown to people (inhibitedBy). With pid above 0 it counts only while a window of that process is shown (a player playing in a window). Like idle-inhibit it counts for nothing while locked unless inhibitorsWorkWhileLocked.
