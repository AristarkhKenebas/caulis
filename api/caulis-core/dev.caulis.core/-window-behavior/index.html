WindowBehavior

data class WindowBehavior @JvmOverloads constructor(val minWidth: Int = 0, val minHeight: Int = 0, val maxWidth: Int = 0, val maxHeight: Int = 0, val animated: Boolean = true, val keepsAwake: Boolean = false, val hiddenFromCapture: Boolean = false, val takesFocus: Boolean = true, val ignored: Set<WindowRequest> = emptySet())

How a window behaves beyond its place and looks — asked of Desktop.behaviorFor whenever it matters, so it may change while the window is open (caulis-wm's rule { } sets it).

desktop.behaviorFor = { window ->
    if (window.appId == "mpv") WindowBehavior(keepsAwake = true, animated = false) else WindowBehavior.USUAL
}
