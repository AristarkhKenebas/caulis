PortalSettings

class PortalSettings(bus: DBusConnection, appearance: Appearance, val busName: String = BUS_NAME) : AutoCloseable

Tells programs the appearance the way xdg-desktop-portal asks its backends (org.freedesktop.impl.portal.Settings: org.freedesktop.appearance color-scheme, accent-color, contrast), on the session bus under busName, and again whenever it changes. The portal uses it where it is told to (a caulis.portal file and a <desktop>-portals.conf line: see the guide); close it to stop.
