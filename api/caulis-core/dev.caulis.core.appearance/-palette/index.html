Palette

class Palette(val seed: Color, val style: PaletteStyle = PaletteStyle.TONAL_SPOT)

Colours made from one colour — a wallpaper's, or one you choose — as phones do (Material You, matugen): a seed and a style give a whole PaletteScheme for light and dark, its roles (primary, surface, text, ...) in tones that read well together.

val seed = Palette.seedOf(wallpaperImage)          // the wallpaper's most telling colour
val palette = Palette(seed, PaletteStyle.VIBRANT)
val dark = palette.scheme(dark = true)
dark.primary; dark.surface; dark.onSurface
palette.code                                        // "caulis-palette:#5b8cc8:vibrant": to share

The tones are made in OKLCH (perceived lightness, colourfulness, hue), so a role has the same lightness whatever the hue.
