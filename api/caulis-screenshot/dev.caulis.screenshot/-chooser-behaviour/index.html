ChooserBehaviour

data class ChooserBehaviour @JvmOverloads constructor(val buttons: List<ChooserButton> = ChooserButton.entries, val timerSteps: List<Int> = listOf(0, 3, 5, 10), val keys: ChooserKeys = ChooserKeys(), val appearMillis: Long = 170, val rise: Int = 16, val doubleClickMillis: Long = 400, val grab: Int = 7, val minDrag: Int = 4, val rememberKind: Boolean = false, val clickPicksWindow: Boolean = false)

How the chooser behaves: its toolbar's buttons (in this order; ChooserButton.WINDOWS shows only over an overview), the timer's timerSteps (seconds, 0: off), its keys, how quickly it comes (appearMillis, the toolbar rising rise units: the desktop's animation "screenshot", off unless animations are on), what counts as a double click (doubleClickMillis), how near an edge of a part the pointer grabs it (grab units) and how far a drag must go to be one (minDrag units). It starts choosing a part (a window is chosen by its key or button): with rememberKind it starts with the kind used last instead, and with clickPicksWindow a click (not a drag) while choosing a part takes the window there.
