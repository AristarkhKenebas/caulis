The chooser's keys, by the names xkb gives them ("a", "Return", "Escape", "space", "Tab"), as shortcuts see them: a letter is the key that types it in your layout (on AZERTY the key of "a" is A, on Dvorak too), on a non-Latin layout the one of the first Latin layout. The tips name the first of each. (The arrow keys move a part: with Shift by ten, with Ctrl they resize it.)
