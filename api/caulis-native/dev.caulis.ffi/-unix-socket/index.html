UnixSocket

class UnixSocket : AutoCloseable

A connected local (unix) socket. Wayland programs talk to the compositor through one.

Besides bytes, a unix socket can carry open file descriptors from one process to another (shared memory, keyboard maps, GPU buffers...). send and receive support that. All calls are non-blocking: they return -1 when they would have to wait; use Epoll to learn when to try again.
