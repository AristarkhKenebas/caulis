NativeMemory

object NativeMemory

The C library's memory: what Skia, the GPU driver, fonts and the like take with malloc.

glibc keeps memory that was freed for later use — in pools of its own (one per few threads) — and gives back only what is at a pool's very end. After the start's work (the first frames, menus drawn ahead, pictures read) tens of megabytes stayed counted to the compositor although nothing used them any more. trim asks glibc to give them back.

limitPools

@JvmStatic
fun limitPools(count: Int): Boolean

At most count of glibc's pools for the threads that malloc from now on (glibc's own choice: up to 8 per CPU core, each keeping what was freed in it — a compositor's few busy threads do not need them). Only this program: started programs keep glibc's default. Call it early (threads that malloc'd before keep their pools). Returns false where it cannot (not glibc).

@JvmStatic
fun trim(): Long

Gives freed memory back to the system (glibc's malloc_trim). Takes a few milliseconds and holds other threads' malloc meanwhile: call it now and then (after the start, after a big menu closed), from any thread — not for every frame. Returns how much smaller the program got in kB (the resident memory before and after), or -1 if it cannot trim here.
