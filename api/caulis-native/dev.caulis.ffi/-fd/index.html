Fd

class Fd : AutoCloseable

An open file descriptor that this program owns.

The rule is simple: whoever holds an Fd must close it, and it is closed exactly once. Use it with use { } so it is closed even when something throws:

Fd.adopt(raw).use { fd -> ... }
Content copied to clipboard

To hand the descriptor to someone else (for example, to send it to another process), call release: after that this object no longer owns it and will not close it.
