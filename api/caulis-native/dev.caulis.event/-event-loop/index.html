EventLoop

class EventLoop : AutoCloseable

The main loop: waits for file descriptors to become ready and calls their handlers.

Everything in a compositor (clients, input devices, the display) is a file descriptor, so one loop on one thread drives it all. Handlers must return quickly and never block: a slow handler delays every frame.

EventLoop().use { loop ->
    loop.add(socket.fd) { ready -> if (ready.readable) ... }
    loop.run()   // until loop.stop()
}
