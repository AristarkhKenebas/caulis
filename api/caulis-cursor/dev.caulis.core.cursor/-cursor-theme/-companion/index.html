fun load(name: String? = null, size: Int? = null): CursorTheme

Loads the theme name at size pixels. Without a name: a theme that came with a library, else the one in XCURSOR_THEME, else Caulis's own (DEFAULT, sharp white arrows). Without a size: XCURSOR_SIZE, else 24. Cursors a theme lacks come from the system's theme, then from Caulis's own, so there always is one.
