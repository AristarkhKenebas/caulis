compose

fun Caulis.compose(place: (Monitor) -> Rect?, level: DrawingLevel = DrawingLevel.ON_TOP, reserve: (Monitor) -> Reserve? = { null }, takesKeyboard: Boolean = false, sceneSize: (Monitor) -> SceneSize? = { null }, appearance: (Monitor) -> WidgetLook = { WidgetLook.SHOWN }, moving: () -> Boolean = { false }, onPressOutside: (x: Double, y: Double, onAnother: Boolean) -> Boolean = { _, _, _ -> false }, recovery: ComposeRecovery = ComposeRecovery.DEFAULT, showsWhileLocked: Boolean = false, content: @Composable (monitor: Monitor) -> Unit): ComposeHandle

A part of this compositor's own interface in Compose (ComposeWidget):

  • place: where it is on each monitor (desktop units; null: not there),

  • level: among the windows: on top of everything (the default), above or below them,

  • reserve: room it keeps at an edge (a bar; windows make way),

  • takesKeyboard: a click gives it the keyboard (text fields, a launcher),

  • sceneSize: the scene's size, when it is not its area's (an area that grows and shrinks without the scene being made anew: see ComposeWidget),

  • appearance: how its picture is shown (see-through, bigger, moved, unfolding — see WidgetLook), done by the compositor without drawing it again,

  • moving: true while appearance changes by itself (frames keep coming),

  • onPressOutside: a press elsewhere (x, y, on another widget): true takes it (a menu closed),

  • recovery: what happens when its content throws (logged, started over: ComposeRecovery),

  • showsWhileLocked: shown and used while the session is locked too (an on-screen keyboard),

  • content: what it shows on a monitor.

A lock screen of your own: desktop.lockInternally(handle.widget!!) (once the compositor runs; see dev.caulis.core.Desktop.lockInternally).

Copying and pasting in its text fields use the compositor's clipboard. Close the result to take it away (a reload of the configuration does too); it also has the widget once the compositor runs.

compose(place = { m -> Rect(m.area.x, m.area.y, m.area.width, 32) }, reserve = { Reserve(Edge.TOP, 32) }) { monitor ->
    Row(Modifier.fillMaxSize().background(Color(0xE01E1E2E)), verticalAlignment = Alignment.CenterVertically) {
        Text("  ${monitor.name}", color = Color.White)
    }
}
