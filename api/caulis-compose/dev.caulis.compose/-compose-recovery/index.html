ComposeRecovery

class ComposeRecovery @JvmOverloads constructor(val delayMillis: Long = 500, val maxDelayMillis: Long, val forgetAfterMillis: Long, val notice: String? = "A part of the desktop written in Compose failed and starts over: {error}", val onError: (error: Throwable) -> Unit = {})

What a ComposeWidget does when its content fails — an exception thrown in a composable, in a LaunchedEffect, in a click's handler or while it is drawn. Compose stops such a scene for good (nothing is composed or drawn anew in it), so the widget makes it anew: the error is logged (area "compose"), onError is told, and after delayMillis the scene starts over (state kept with remember in it too). Until then it shows what it showed last and takes no input. Failing again soon after doubles the wait each time, up to maxDelayMillis: content that fails at once does not take every frame.
