WidgetLook

data class WidgetLook @JvmOverloads constructor(val alpha: Float = 1.0f, val scale: Float = 1.0f, val dx: Float = 0.0f, val dy: Float = 0.0f, val reveal: Float = 1.0f, val revealFrom: Edge = Edge.TOP)

How a ComposeWidget's picture is shown: alpha as strong, scale times its size about its area's middle, moved by dx, dy (desktop units), reveal of it shown from the edge revealFrom. The compositor does it with the picture as it is, so appearing and going away cost no drawing. The pointer follows the picture: a click lands where it is seen (only on the part shown, while its area is where the pointer is looked for).
