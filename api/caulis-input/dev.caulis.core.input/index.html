EarlyPointer
Link copied to clipboard
interface EarlyPointer

Told of the pointer's movement on the input thread, before the compositor's thread handles it (InputDevices.ownThread): the cursor can move at once even while the compositor's thread is busy. dev.caulis.core.Desktop.earlyPointer is one: it moves the cursor plane. All three are called by InputDevices; another backend reading input on a thread of its own may call them the same way.

Gesture

sealed interface Gesture

A touchpad gesture with several fingers: swipe (move), pinch (zoom/rotate) or hold (fingers resting). Each one comes as Begin, any number of Updates, and End. Times are in milliseconds.

InputSettings
Link copied to clipboard
class InputSettings

Settings of all pointing devices: those of every pointer, on top of them those of touchpads, on top of those a device's own (by its name, as --devices lists them; * matches anything: "Logitech*"). Drawing tablets have tablets of their own (a left-handed mouse does not turn the tablet around), with a device's own on top.

TabletArea
Link copied to clipboard
data class TabletArea(val x: Double, val y: Double, val width: Double, val height: Double)

The part of a tablet that is used, each value 0..1 of its whole drawing area as the user sees it (turned around when DeviceSettings.leftHanded): TabletArea(0.0, 0.0, 0.5, 0.5) is its top left quarter. Pen positions outside it go to the nearest edge.
