Xwayland

class Xwayland(display: Display, desktop: Desktop, loop: EventLoop, clipboard: DataDeviceManager? = null, idleSeconds: Int = 10, wholeScaleWorlds: Boolean = true, wholeScaleOf: (pid: Int) -> Int? = WholeScalePrograms::scaleOf) : AutoCloseable

X11 programs in the compositor. Their display (displayName, e.g. ":1", what DISPLAY is set to) is open at once, but Xwayland itself is started only when the first X11 program connects — no memory or start-up time is spent while none runs — and stops by itself idleSeconds after the last one left; the next starts it again.

Their windows are managed by Xwm: they tile, float, get title bars and effects, show in docks and screen sharing like Wayland windows, and copy and paste works between X11 and Wayland programs (give the clipboard).

Scaled screens: X works in the screen's real pixels and programs are told the real DPI (Xft.dpi) and cursor size, so they are as sharp and as big as Wayland programs. Programs that only know whole scales — Java (Swing, AWT) — cannot draw at 1.5: with wholeScaleWorlds, they get an Xwayland of their own that works in a whole number of pixels per unit (their scale, e.g. 2), and are shown at exactly the screen's scale — sharp (made smaller, never larger), the right size, every part clickable. The display then is a door (XRouter) that joins each program to its Xwayland.
