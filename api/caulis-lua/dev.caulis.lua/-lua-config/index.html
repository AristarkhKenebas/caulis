class LuaConfig : ConfigLanguage

config.lua: the configuration in Lua. One table, caulis, says everything:

caulis.settings {                                  -- what config.json can say
  layout = { name = "master-stack", gaps = { inner = 8 } },
  keys = { quit = false },
}
caulis.bind("Super+B", "exec firefox")             -- an action, as text
caulis.bind("Super+N", function() caulis.notify("Hello") end)
caulis.rule { appId = "mpv", floating = true }
caulis.on("window-opened", function(w)
  if w.appId == "firefox" then caulis.run("move-to-workspace 2", w.id) end
end)
local clock = caulis.every(1000, function() ... end)  -- every second; clock.cancel() stops it
local key = caulis.bind("Super+G", "exec gimp")      -- key.setEnabled(false), key.unbind()
caulis.layout("halves", function(windows, area, focused)
  -- one rectangle per window: { x =, y =, width =, height = }
end)

A mistake is reported with its line and the rest still applies. Lua code that runs too long (a loop that never ends, also inside pcall, a coroutine or a string pattern that backtracks without end) is stopped, so the desktop does not freeze. Code that needs more memory than there is is stopped too, and then nothing of config.lua runs any more until it is read again (a save, a reload). It is your own code, as trusted as config.kts: os and io are there, and what would surely stop the desktop is taken out of them (reading a pipe or a terminal you open yourself still waits). os.execute and caulis.launch start a program inside the compositor without waiting for it (at the top of the file: once, when the compositor starts — not on each save, not for --check-config); io.popen and os.exit are not there (caulis.run("quit") quits), the standard input is empty. The debug hooks, Java itself (luajava) and Java classes through require are not there either: require finds only Lua files next to config.lua. Code typed at --repl (or sent with --lua) runs in this same state, with its variables. One call into it (a key, an event, a layout) may run Caulis.scriptCallLimitMillis.

A ConfigLanguage: Caulis finds it by itself when caulis-lua is on the class path — there is nothing to call.
