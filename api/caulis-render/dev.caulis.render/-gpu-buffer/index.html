GpuBuffer

@SubclassOptInRequired(markerClass = [InternalCaulisApi::class])
interface GpuBuffer : GpuTarget

A GpuTarget backed by a shareable GPU buffer. Its memory can be shown by the display (with handle, a number valid on the renderer's DRM device) or given to others (export).
