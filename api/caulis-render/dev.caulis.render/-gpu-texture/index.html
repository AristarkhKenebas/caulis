GpuTexture

@SubclassOptInRequired(markerClass = [InternalCaulisApi::class])
interface GpuTexture : AutoCloseable

A picture on the GPU, made by a Renderer (only its own can be drawn: a class of yours implementing this cannot, so implementing it needs @OptIn(InternalCaulisApi::class)).

abstract fun upload(pixels: MemorySegment, firstRow: Int, rowCount: Int)

Copies rows firstRow until firstRow + rowCount from pixels (tightly packed rows of width * 4 bytes, starting with row firstRow). pixels must be memory Caulis owns, never a client's shared memory: the driver reads it in C, where a client shrinking the memory would crash the compositor.
