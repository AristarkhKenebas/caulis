Shader

class Shader(source: () -> String, val name: String, val alpha: Float, val colors: List<Color>) : Paint

A shader of your own: GLSL (OpenGL ES 3) with vec4 paint(vec2 at) — at is 0..1 in the box being filled (the window and its border, or its shadow); return a plain (not premultiplied) colour. code is asked each time it is drawn (a file can change); name is what messages call it. What it can read besides at:

  • float time — seconds, going on while it is seen (0 when its border says animate = false)

  • vec2 size — the box in pixels; vec2 pixel — this pixel in it, from its top left corner

  • float borderWidth, float cornerRadius — in pixels (0 for a shadow's width)

  • float progress — how far along the border this pixel is, 0..1 clockwise from the top left corner

  • float focused, float urgent, float grouped — 1.0 or 0.0, the window's state (PaintState)

  • vec4 colors[8], int colorCount — colors given to it (plain, not premultiplied)

If it does not compile, the compositor says so (with the line) and draws its first colour instead — never a black or frozen screen.
