Renderer

interface Renderer : AutoCloseable

Draws Caulis's pictures on the GPU. The rest of Caulis only talks to this interface, so the drawing technology can be swapped: OpenGL ES today (dev.caulis.render.gles), Vulkan later.

Coordinates are pixels, (0, 0) is the top left corner of the target. Colours are 0..1. A renderer belongs to the thread that created it (the event loop thread).

Blurs what was drawn so far under area (frosted glass behind a see-through window), its corners rounded by cornerRadius. size is how strong the blur is, passes how smooth (each pass doubles the reach).
