Dmabuf

class Dmabuf(val width: Int, val height: Int, val format: Int, val modifier: Long, val planes: List<Dmabuf.Plane>) : AutoCloseable

A GPU buffer described by file descriptors (Linux "dma-buf"): how programs, the GPU and the display share pictures without copying them.

format is a DRM fourcc code (e.g. XRGB8888 = 'XR24'), modifier describes the memory layout (0 = plain rows, others = GPU-specific tiling).
