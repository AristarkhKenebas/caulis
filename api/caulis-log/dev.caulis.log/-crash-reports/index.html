CrashReports

object CrashReports

Reports of what stopped the compositor (or one of its threads): a text file that says what failed and where, on what system, with what the log had just before. Secrets, names and titles are taken out (Redactor), so a report can be sent as it is.

Set folder to have them written; Log alone writes none.
