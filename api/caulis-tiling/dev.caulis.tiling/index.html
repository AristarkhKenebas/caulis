class BinaryTree @JvmOverloads constructor(gaps: Gaps = Gaps(), insertion: Insertion = Insertion.LONGEST_SIDE, name: String = "Tree", splitRatio: Double = 0.5) : RememberingLayout

Windows in a tree of splits: every new window splits the focused one in two (like bspwm; for i3-style tiling see ManualTiling). The tree is remembered, so you can preselect where the next window goes, swap windows, move the split lines, rotate and balance. A new split gives the new window 1 - splitRatio of the space.

Canvas
Link copied to clipboard
class Canvas @JvmOverloads constructor(gaps: Gaps = Gaps(), columns: Int = 2, rows: Int = 2, windowColumns: Int = 1, windowRows: Int = 2) : RememberingLayout

One big canvas, as in newm: windows lie on an endless grid of cells, and the screen shows a part of it (columns × rows cells). Nothing is squeezed — new windows go into free cells next to the focused one; you move the view over the canvas (TilingCommand.Pan), move windows by a cell (TilingCommand.Move) and make them bigger or smaller by a cell (TilingCommand.Resize). Focusing a window anywhere on the canvas brings it into view (that is how a dock or Alt+Tab shows a window that is far away).

ManualTiling

class ManualTiling @JvmOverloads constructor(gaps: Gaps = Gaps()) : RememberingLayout

Tiling as in i3: windows live in containers that are either side by side or on top of each other. A new window joins the focused window's container (all get equal shares), or — after TilingCommand.SplitNext in the other direction — the focused window and the new one get a container of their own.

ScrollingColumns
Link copied to clipboard
class ScrollingColumns @JvmOverloads constructor(gaps: Gaps = Gaps(), widths: List<Double> = listOf(1.0 / 3, 0.5, 2.0 / 3, 1.0), newWidth: Double = 0.5, centerFocused: Boolean = false) : RememberingLayout

Columns on an endless strip that scrolls sideways, as in niri: a new window opens as a new column right of the focused one, so nothing else gets squeezed. A column can hold several windows on top of each other (TilingCommand.Consume moves a window into the neighbouring column or out into its own). The view scrolls only as far as needed to show the focused column.
