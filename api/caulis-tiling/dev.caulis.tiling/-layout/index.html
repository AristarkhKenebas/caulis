Layout

interface Layout

Decides where tiled windows go. A layout gets the windows (in their tiling order, oldest first) and the free area, and returns one rectangle per window, in the same order.

That is the whole contract, so a layout is easy to write — in Kotlin, Java, or later in any scripting language:

object Columns : Layout {
    override val name = "Columns"
    override fun arrange(windows: List<LayoutWindow>, area: Rect, focused: Int) =
        Split.evenly(area, windows.size, gap = 8, vertical = false)
}

Rectangles may lie outside the area (scrolling layouts); those windows are simply not on screen. Layouts must not keep state about windows: everything they need is passed in, so they can be swapped at any moment.
