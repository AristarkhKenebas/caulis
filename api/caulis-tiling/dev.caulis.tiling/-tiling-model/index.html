TilingModel

interface TilingModel

The arrangement of one workspace, for layouts that remember things: a tree of splits (bspwm, i3), columns (niri), a canvas (newm). Each workspace gets its own model from Layout.createModel.

The model gets the full list of tiled windows on every arrange and brings itself up to date (new windows are placed next to the focused one, gone ones are dropped), so it can never lose a window. It must always show the focused window — scrolling or panning to it if needed — which makes "activate this window" (from a dock, Alt+Tab, ...) work the same with every layout.
