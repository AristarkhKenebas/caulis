PluginScope

class PluginScope : AutoCloseable

What one enabling of a plugin registered, taken away when it is disabled, the last first. Every API a plugin gets adds to it; for what the API does not know (a socket, a thread of a library), add and onClose. Thread-safe. What is added after the end is closed at once, so a thread of the plugin that was still busy cannot leave something behind.
