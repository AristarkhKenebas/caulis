data class ApiVersion(val major: Int, val minor: Int)

The version of an API, major.minor. A plugin written for 1.2 runs on 1.2 and 1.5, not on 1.1 or 2.0. While the major is 0 the same holds: within 0.x the minor only grows when the API does, and what breaks plugins raises the major's successor in the changelog.

PluginScope
Link copied to clipboard
class PluginScope : AutoCloseable

What one enabling of a plugin registered, taken away when it is disabled, the last first. Every API a plugin gets adds to it; for what the API does not know (a socket, a thread of a library), add and onClose. Thread-safe. What is added after the end is closed at once, so a thread of the plugin that was still busy cannot leave something behind.

PluginWatchdog
Link copied to clipboard
class PluginWatchdog

Watches the calls into plugins on the compositor's thread, from a thread of its own. It only exists while a plugin is loaded or a class loader is waited for: with no plugin there is no thread at all. It also looks whether the class loaders of unloaded plugins were collected.
