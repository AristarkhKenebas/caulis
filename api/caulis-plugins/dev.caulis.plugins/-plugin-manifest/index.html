PluginManifest

data class PluginManifest(val id: String, val version: PluginVersion, val apis: Map<String, ApiVersion>, val main: String? = null, val name: String = id, val description: String = "", val dependencies: List<PluginDependency> = emptyList())

What a plugin says of itself: caulis-plugin.properties at the top of a jar (or in a plugin's folder), in Java's properties format:

id = my-plugin                     # small letters, digits and -; its name everywhere
version = 1.2.0
api = caulis:0.1                   # the API it was written for; several: caulis:0.1, newm:0.1
main = org.example.MyPlugin        # (jar plugins) the class that implements Plugin
name = My plugin                   # optional: what people read
description = Says hello           # optional
depends = other-plugin>=1.0, nice-to-have?     # optional
