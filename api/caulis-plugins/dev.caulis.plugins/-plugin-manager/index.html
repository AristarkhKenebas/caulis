PluginManager

class PluginManager<H : Any>(host: PluginHost<H>, options: PluginOptions, formats: List<PluginFormat<H>> = emptyList()) : AutoCloseable

Runs a compositor's plugins: finds them in folders, orders them by what they depend on, loads, enables, disables, unloads and hot-reloads them. Everything but reading files happens on the compositor's thread, where all its functions must be called.

Whatever a plugin does wrong stays its own problem: a throw disables it with a notice, a hang is detected and reported, a new file that does not work leaves the old one running. With no plugin in the folders, this is one object and one thread waiting in the kernel.
