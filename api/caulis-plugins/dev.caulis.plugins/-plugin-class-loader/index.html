PluginClassLoader

class PluginClassLoader(name: String, urls: Array<URL>, parent: ClassLoader, shared: List<String>, dependencies: List<PluginClassLoader> = emptyList()) : URLClassLoader

One plugin's classes: its jar first, so plugins cannot collide over a library, then the plugins it depends on, then the compositor's. The packages in shared always come from the compositor (the API, Kotlin, the JDK), also when the jar brings its own copy: two copies of an interface would not fit each other.
